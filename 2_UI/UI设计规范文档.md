# 智聘·双向精准匹配引擎 — UI设计规范文档

## 一、设计理念

### 1.1 设计方向
**深海科技 · 克制的未来感**

以深海夜色为基调，融合科技蓝与青碧色作为视觉焦点，暖金色用于成就强调。整体呈现专业、可信赖又不失温度的品牌调性，呼应"去标签化公平匹配"的核心理念。

### 1.2 设计关键词
- **信任感**：深海蓝 + 磨砂玻璃 + 柔和投影
- **精准**：卡片式布局 + 明确的信息层级
- **成长**：曲线可视化 + 渐进式动画
- **公平**：去标签化设计 + 能力为核心的信息架构

## 四、组件规范

### 4.1 按钮

#### 主按钮 (btn-primary)
```

圆角: 8px
内边距: 12px 28px
阴影: 0 4px 20px rgba(26,115,232,0.4) (hover)

```

文字: #E2E8F0, Space Grotesk, 600
hover: border-color -> #1A73E8, bg -> rgba(26,115,232,0.08)
```

```

文字: #0A0F1A, Space Grotesk, 600
阴影: 0 4px 20px rgba(240,165,0,0.4) (hover)
```

## 六、交互规范

### 6.1 动效时间表

| 动效 | 时长 | 缓动函数 | 触发条件 |
|------|------|----------|----------|
| 页面元素入场 | 0.5s | easeOut | 进入视口 |
| 卡片hover | 0.3s | ease | 鼠标悬停 |
| 模态框弹出 | 0.4s | easeOut (scale 0.95→1) | 点击触发 |
| 进度条填充 | 0.5s | easeOut | 答题进度变化 |
| 柱状图展开 | 0.8s | easeOut | 结果页渲染 |
| shimmer动画 | 2.5s | ease-in-out (循环) | 持续 |
| 脉冲光晕 | 2s | ease-in-out (循环) | 当前位置标记 |
| 浮动动画 | 6s | ease-in-out (循环) | 持续 |

### 6.2 页面过渡
- 路由切换：无全局过渡，各页面独立入场动画
- 模态框：背景模糊 + 缩放淡入
- 标签切换：淡入淡出重置

### 6.3 反馈机制
- 按钮点击：hover缩放 + 阴影变化
- 评分hover：实时预览星级
- 删除确认：二次确认模态框，红色警告色调
- 提交成功：绿色勾选动画 + 成功消息

## 七、响应式断点

| 断点 | 屏幕宽度 | 布局策略 |
|------|----------|----------|
| 桌面端 | ≥1024px | 多栏布局，导航完整展示 |
| 平板端 | 768px - 1023px | 单栏居中，表格转卡片堆叠 |
| 移动端 | <768px | 全宽单列，汉堡菜单，底部操作栏 |

### 移动端适配规则
- 按钮最小点击区域: 44×44px
- 卡片间距: 12-16px
- 字体缩放: 标题缩小20%，正文保持
- 表格隐藏，转为卡片列表
- 模态框全屏显示

## 八、页面路由与用户流程

### 8.1 路由表

| 路由 | 页面 | 入口 |
|------|------|------|
| `/` | 首页工作台 | 默认入口 |
| `/select-position` | 岗位选择 | 求职者/大学生点击"生成技能画像" |
| `/quiz` | 题库测评 | 选择岗位后 / HR自主答题 |
| `/quiz/hr-ai` | HR-AI代答 | HR选择AI代答模式 |
| `/result` | 画像结果 | 答题提交后 |
| `/growth` | 成长模式 | 结果页"进入成长模式" |
| `/hr/jobs` | 岗位库管理 | HR工作台 |
| `/match` | 双向匹配 | 求职者"岗位库匹配" / HR"匹配人才库" |
| `/evaluate` | 信誉评价 | 匹配结果页 |

### 8.2 用户流程图

```
求职者:
首页 → 选择岗位 → 答题(可跳过) → 提交 → 画像结果
                                              ├── 录入数据库
                                              ├── 岗位匹配 → 匹配列表 → 匿名沟通
                                              └── 成长模式 → 曲线+规划 → 保存记录

HR:
首页 → [自主答题|AI代答] → 岗位画像结果
                              ├── 录入岗位库
                              └── 岗位管理 → 匹配人才 → 匿名沟通 → 评价
```

## 九、技术实现参考

```
src/
├── components/
│   └── Layout.tsx          # 全局布局 (Header + Footer + Outlet)
├── pages/
│   ├── DashboardPage.tsx    # 首页工作台 (3种模式)
│   ├── PositionSelectPage.tsx # 岗位选择
│   ├── QuizPage.tsx         # 题库测评
│   ├── HRAssistPage.tsx     # HR-AI代答
│   ├── ResultPage.tsx       # 画像结果
│   ├── GrowthPage.tsx       # 成长模式
│   ├── HRJobManagePage.tsx  # 岗位库管理
│   ├── MatchPage.tsx        # 双向匹配
│   └── EvaluatePage.tsx     # 信誉评价
├── store/
│   └── useAppStore.ts      # Zustand全局状态
├── App.tsx                  # 路由配置
├── main.tsx                 # 入口

### 技术栈
- React 18 + TypeScript + Vite 6
- Tailwind CSS 3 (自定义颜色/动画/字体)
- React Router v6
- Zustand 5 (状态管理)
- Framer Motion 11 (动画)
- Lucide React (图标)

### 开发服务器
```bash
npm run dev    # http://localhost:5173
npm run build  # 生产构建
npm run check  # TypeScript 类型检查
```

## 十、视觉预览说明

项目已完整实现并可运行。主要视觉特征：

1. **深色主题** — 深海蓝背景 + 网点纹理 (dot-bg)
2. **磨砂玻璃导航** — glass + backdrop-blur
3. **渐变色强调** — 科技蓝→青碧色渐变 (text-gradient)
4. **Shimmer按钮动画** — 主CTA按钮持续光泽扫过
5. **脉冲位置标记** — 成长曲线上的SVG动画圆点
6. **Framer Motion入场** — 各页面元素依次淡入/滑入
7. **匹配度环形图** — SVG环形进度条直观展示
8. **星级hover预览** — 评价页实时预览评分效果
